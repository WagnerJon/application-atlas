Application Atlas 1.1.0 adds deadlines and a small celebration for your first offer.

- New **Deadlines** sidebar tab: only applications with a deadline, upcoming dates closest first, then overdue entries.
- **Days till deadline** shows days left, due today, or days overdue, using calendar days.
- A one-time congratulations prompt after the first newly recorded offer includes an optional [Buy Me a Coffee](https://buymeacoffee.com/wagnerjon) link. Dismiss it freely; all features remain free. Existing offers and backup restores do not trigger it.

## Download

Choose **Application-Atlas-1.1.0-macOS-universal.zip** for Apple Silicon or Intel, running macOS 14 or later. Source code assets do not contain the compiled app.

This app is **not notarized and has no Apple Developer ID signature**. Read the attached **INSTALL.md** for Apple's per-app Open Anyway procedure. Keep Gatekeeper enabled.

The attached SHA256SUMS.txt verifies the ZIP. Create a backup before updating, quit the app, and replace the old copy. Your local applications and documents are retained. There is no automatic updater.
