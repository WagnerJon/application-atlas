A lightweight native macOS tracker for job, PhD, and custom application categories.

- Application journeys with editable statuses and dates, a clickable Sankey, and waiting-day counts.
- Cover-letter attachments, status-colored map routes, customizable categories and icons.
- CSV export, complete backups, and restore.
- MIT licensed, with optional support at https://buymeacoffee.com/wagnerjon.

## Download

Choose the **macOS-universal.zip** asset for Apple Silicon or Intel, on macOS 14 or later. “Source code” assets do not contain the compiled app.

This app is **not notarized and has no Apple Developer ID signature**. macOS normally blocks the initial launch. Read the attached **INSTALL.md** for Apple's per-app Open Anyway procedure. Do not disable Gatekeeper.

The attached SHA256SUMS.txt verifies the ZIP. Back up your data before updating. There is no automatic updater.
