# Contributing

Small, focused improvements that keep Application Atlas lightweight are welcome. For substantial features, open an issue first.

Install Apple's Command Line Tools (`xcode-select --install`) or Xcode, then run:

```sh
./scripts/test.sh
./scripts/build.sh
```

Describe the problem, the change, and how you tested it in your pull request. Use fictional applications and documents in tests and screenshots. Never include personal backups, documents, or credentials. Contributions are provided under the project's MIT license.
